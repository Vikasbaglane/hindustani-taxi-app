# हिंदुस्तानी टॅक्सी

Marathi-language React Native + Expo demo for Passenger, Driver and Admin.

## Features
- Role selection
- Passenger ride booking
- Vehicle selection
- UPI QR payment demo
- Driver dashboard
- Admin dashboard
- Static UI; no backend required

## Run
```bash
npm install
npx expo start
```

For Android, press `a` in the Expo terminal or use Expo Go.
